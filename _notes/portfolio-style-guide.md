# Portfolio Style Guide

## Graphics Colors

Use this background color for portfolio graphics made in Mermaid.ai or similar tools:

- RGB: `rgb(45, 45, 78)`
- Hex: `#2D2D4E`

Purpose: keep diagrams visually consistent with the dark blue/purple theme of the portfolio site.

## Current Site Theme Notes

- Main portfolio background: dark navy / slate
- Accent color: light cyan / blue
- Prefer clean, high-contrast graphics
- Avoid overly bright or unrelated color palettes
